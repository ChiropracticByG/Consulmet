Consulmet Desk Health

A workplace wellness web app built for Consulmet, developed by Chiropractic by G.

Consulmet Desk Health gives office-based employees practical, evidence-based guidance for desk-related stiffness, posture, mobility and stress — built on the workstation and posture assessments carried out on-site by Chiropractic by G.

Features
12 focus areas — Neck Stiffness, Desk Posture, Upper Back Mobility, Lower Back Health, Shoulder Tightness, Tension Headaches, Core Strength, Hip Mobility for Sitting, Daily Mobility Routine, Stress and Recovery, Walking Breaks, and Healthy Habits
72 exercises and strategies, each with instructions, why it helps, common mistakes, sets/reps/frequency and a completion tick
Today's Desk Routine — a 5-minute guided daily flow
Movement Snacks — 2 / 5 / 10-minute break routines
Traffic-light (green / amber / red) guidance and red-flag safety information
Daily check-in that suggests where to focus
Break timer, hydration tracker, walking tracker
Weekly Wellbeing Score and per-topic progress tracking
"Ask Your Chiropractor" FAQ
Fully offline, installable as an app (PWA) — no account, no server, no internet connection required after first load
All progress is stored only on the employee's own device (with optional export/import as a backup file)
Getting started

This is a single self-contained HTML file — there is no build step and no dependencies.

Download ConsulmetDeskHealth.html
Open it in any modern browser (Chrome, Safari, Edge, Firefox)
Optional: use the browser's "Add to Home Screen" / "Install App" option, or the Install app button in the app's About tab, to add it as a standalone app

To distribute it to employees, simply send them the HTML file (email, shared drive, Slack, etc.) — no hosting is required, though it can also be dropped onto any static file host if a shareable link is preferred.

Renewing the license
Open ConsulmetDeskHealth.html in a text editor
Find the LICENSE_EXPIRY constant near the top of the <script> section
Update it to the new expiry date
Save the file and re-send it to the client — the new file fully replaces their old copy

No license keys, accounts, or server involved.

Note: because this is a single offline HTML file, the expiry check is a straightforward, editable safeguard rather than tamper-proof DRM — it enforces the license in normal use but is not designed to withstand deliberate tampering with the source code.
